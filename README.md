# LOHVC

## 📚 Sobre o projeto

O **LOHVC** é uma plataforma educacional desenvolvida com o objetivo de facilitar a organização e o gerenciamento de conteúdos educacionais.

O projeto foi desenvolvido como parte da minha formação acadêmica, envolvendo conceitos de desenvolvimento web, banco de dados e integração entre front-end e back-end.

## 🚀 Tecnologias

* PHP
* PostgreSQL
* HTML5
* CSS3
* JavaScript
* XAMPP

## ⚙️ Funcionalidades

* Gerenciamento de conteúdos educacionais
* Interface web para interação com a plataforma
* Persistência de dados em banco PostgreSQL
* Integração entre front-end e back-end
* Estrutura organizada para evolução do sistema

## 🗄️ Banco de dados

O projeto utiliza **PostgreSQL** para armazenamento e gerenciamento dos dados.

Durante o desenvolvimento, o banco foi estruturado para atender às necessidades da plataforma e suas funcionalidades.

## 💻 Execução

Para executar o projeto localmente:

1. Instale o XAMPP.
2. Configure o ambiente PHP.
3. Configure o banco PostgreSQL.
4. Importe/execute os scripts necessários do banco de dados.
5. Coloque o projeto no diretório apropriado do servidor local.
6. Inicie o servidor e acesse a aplicação pelo navegador.

## 🎯 Objetivo acadêmico

O projeto foi desenvolvido para colocar em prática conhecimentos de:

* Desenvolvimento web
* Banco de dados
* PHP
* HTML, CSS e JavaScript
* Modelagem e manipulação de dados
* Integração entre diferentes tecnologias
